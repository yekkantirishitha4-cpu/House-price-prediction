# 🏠 House Price Prediction Using Machine Learning

## 📌 Overview
House Price Prediction is a Machine Learning project developed using Python in Google Colab. It predicts the estimated price of a house based on features such as area, number of bedrooms, and number of bathrooms.

The project uses **Linear Regression**, a supervised machine learning algorithm, to learn relationships between housing features and prices.

## 🎯 Objectives
- Understand the basics of Machine Learning and regression.
- Analyze housing data using Python.
- Train a Linear Regression model.
- Evaluate model performance using regression metrics.
- Predict the estimated price of a new house.

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## ⚙️ Project Workflow
1. Import the required Python libraries.
2. Load and explore the housing dataset.
3. Prepare input features and target values.
4. Split the data into training and testing sets.
5. Train the Linear Regression model.
6. Evaluate the model using MAE, RMSE, and R² score.
7. Predict the price of a new house.

## 📊 Input Features
- **Area:** Size of the house in square feet.
- **Bedrooms:** Number of bedrooms.
- **Bathrooms:** Number of bathrooms.

**Target Variable:** House Price.

## 🚀 How to Run the Project
1. Open [Google Colab](https://colab.research.google.com/).
2. Create a new Python notebook.
3. Copy the project code into notebook cells.
4. Run each cell in sequence.
5. View the model evaluation metrics and predicted house price.

## 📈 Model Evaluation
The model is evaluated using the following metrics:

- **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted prices.
- **Root Mean Squared Error (RMSE):** Measures prediction error while penalizing larger errors more heavily.
- **R² Score:** Measures how well the model explains variation in house prices.

## ✅ Expected Outcome
The project trains a regression model and generates an estimated house price based on the given house features.
